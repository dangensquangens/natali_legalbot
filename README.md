# LegalBot

Учебное веб-приложение по цифровому праву России. На главной странице находится чат. Статистика обращений доступна преподавателю по отдельному адресу с паролем.

## Локальный запуск

1. Распакуйте проект и откройте его папку в терминале. Нужен Python 3.10 или новее. Дополнительные библиотеки устанавливать не требуется.
2. Запустите программу командой:

       py -3 main.py

   Если Python запускается командой python, выполните python main.py. Если установлен uv и уже доступен Python 3.12, можно использовать команду:

       uv run --offline --no-project --python 3.12 main.py

3. Откройте [чат](http://127.0.0.1:8080/). Для [статистики](http://127.0.0.1:8080/admin.html) используйте пароль из окна терминала. Он создаётся для текущего запуска.
4. Для остановки нажмите Ctrl+C. Чтобы выбрать другой порт, добавьте --port 8081 к команде запуска.

## Проверка функций

- Введите «Можно ли отозвать согласие на обработку персональных данных?». В ответе появятся норма закона и пояснение ведомства.
- Введите «Фото выложили без разрешения». Чат предложит выбрать между правом на изображение и авторским правом. Уточнение откроет карточку с текстом применимой статьи ГК РФ.
- Введите вопрос вне базы. Чат предложит уточнить ситуацию или выбрать пример.
- Откройте страницу статистики. После ввода пароля видны количество запросов, результаты поиска, распределение по темам и дням, а также популярные карточки. Каждая отправка, включая выбор варианта уточнения, учитывается отдельно.

## Исходный код и данные

| Файл или папка | Назначение |
|---|---|
| main.py | Точка входа, обработка запросов, закрытый доступ к статистике |
| lookup.py | Подбор карточек по словам и фразам из вопроса |
| knowledge.py | Десять тем, справочные ответы и пояснения ведомств |
| legal_norms.json | Полные тексты статей с прямыми ссылками на источник |
| site/ | Интерфейс чата и страницы статистики |
| data/statistics.sqlite3 | Локальная база агрегированных счётчиков, создаётся при запуске |

Тексты вопросов не записываются в базу. SQLite хранит количество обращений по дате, теме, карточке и результату. Границы дня определяются по московскому времени. Новые ситуации добавляются в knowledge.py. Тексты статей сверены 13 ноября 2026 года. При обновлении карточек сверяйте действующую редакцию нормы по ссылке на статью и обновляйте legal_norms.json.

Для редакции карточек использованы учебные пособия [В. Э. Волкова «Цифровое право. Общая часть»](https://repo.ssau.ru/handle/Uchebnye-izdaniya/Cifrovoe-pravo-Obshaya-chast-99075) (Самарский университет, 2022, с. 62–64, 86) и [А. А. Чеботаревой «Информационное право»](https://www.miit.ru/content/%D0%9E%D0%B1%D0%BB%D0%BE%D0%B6%D0%BA%D0%B0.pdf?id_vf=24067) (Юридический институт МИИТа, 2014, с. 119–121). Правила и сроки в ответах сверены с законодательством.

## Чат на GitHub Pages

Папка docs содержит готовый сайт. Чтобы обновить его после редактирования карточек или интерфейса, запустите python build_pages.py и загрузите обновлённую папку docs в репозиторий.

В репозитории откройте Settings → Pages и выберите Deploy from a branch → main → /docs. После публикации откройте ссылку из настроек и отправьте пример вопроса. Браузер загружает справочник и подбирает ответы локально. Для общей закрытой статистики используется версия с Python-сервером.

## Чат и закрытая статистика онлайн

1. Разместите серверную часть на Python-хостинге с HTTPS и постоянным диском для SQLite. Приложение совместимо с WSGI. На Linux-хостинге с установленным Gunicorn точка входа выглядит так:

       gunicorn --bind 0.0.0.0:$PORT 'main:create_app()'

2. В настройках сервера задайте LEGALBOT_DB с путём на постоянном диске, LEGALBOT_ADMIN_PASSWORD с отдельным длинным паролем и LEGALBOT_PAGES_ORIGIN с адресом вида https://ваш-логин.github.io без пути репозитория. Пароль храните в настройках хостинга.
3. Укажите HTTPS-адрес Python-сервера в site/config.js. Опубликуйте содержимое папки site как корень GitHub Pages. Относительные ссылки поддерживают адрес с именем репозитория.
4. Откройте страницу с сети, которую будет использовать преподаватель. Проверьте загрузку списка тем, ответ на вопрос и вход на страницу admin.html. Передайте пароль отдельным сообщением.

Локальный запуск рассчитан на проверку на одном компьютере. Онлайн-версия использует тот же Python-код и ту же базу карточек.
